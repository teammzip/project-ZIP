# ZIP – 자취생 생활 도우미

혼자 사는 사람을 위한 생활 도우미 웹 서비스의 **프런트엔드 프로토타입**입니다.
일정·할 일·월세·공과금·쓰레기 배출·가계부를 관리하고, 동네 지도와 커뮤니티, AI 도우미(데모)를 제공합니다.

> 지금은 서버와 DB 없이 화면 동작만 만든 단계입니다. 입력한 데이터는 **브라우저에만 저장**됩니다(`localStorage`, 키 이름은 `zip-` 으로 시작).
> AI 답변은 정해진 문장이고, 지도는 OpenStreetMap, 장소·배출 요일·커뮤니티 글은 예시 데이터입니다.

---

## 1. 실행 방법

1. VS Code에서 `Live Server`(Go Live)로 열거나, 프로젝트 폴더에서 아무 로컬 웹서버로 엽니다.
   파일을 더블클릭해서 열면 `import` 방식(ES 모듈)이라 **동작하지 않습니다.**
2. 화면 비교 페이지는 `compare.html` 입니다. 위쪽 버튼으로 화면을 바꿔 가며 볼 수 있습니다.

#### 메뉴 구조: PC 왼쪽 메뉴바 = 모바일 ☰ 전체 메뉴 (6개, 같은 항목·같은 순서)
홈 · 사진 · AI · 동네 · 커뮤니티 · **마이페이지**

#### 마이페이지 화면 구조 (메뉴 이름: 마이페이지)
할 일, 일정, 가계부, 알림, 설정(내 정보)을 한 메뉴로 합친 곳입니다. 위쪽의 탭으로 오갑니다. 별도의 "할 일", "일정", "가계부", "알림", "설정", "쓰레기" 메뉴는 없습니다.
```
마이페이지
├─ 할 일
│   ├─ 이번 주 할 일   → js/views/todo.js
│   └─ 쓰레기 배출     → js/views/trash.js
├─ 일정                → js/views/calendar.js   (달력, 일정 추가·수정·삭제, 검색)
├─ 가계부
│   ├─ 수입            → js/views/income.js
│   └─ 지출
│       ├─ 고정 지출   → 월세(rent.js) + 공과금(bills.js) + 합계(fixed.js)
│       └─ 기타 지출   → js/views/spend.js
├─ 알림                → js/views/noti.js   (안 읽은 알림이 있으면 탭과 메뉴에 빨간 점)
└─ 내 정보             → js/views/settings.js   (이름, 동네, 월세, 알림 켜기/끄기, 데이터 초기화, 회원 탈퇴)
```
- 탭과 화면 전환은 `js/core/router.js`가 맡고, 탭 모양은 `css/app.css`(`.my-tab`, `.exp-tab`, `.exp-subtab`), 탭 HTML은 `index.html`(`myHead`, `taskTabs`, `expTabs`, `expSub`)에 있습니다.
- 모바일에서는 상단의 종 아이콘이 "알림" 탭으로, 동그란 프로필 아이콘이 "내 정보" 탭으로 연결됩니다.

#### 로그아웃과 회원 탈퇴
- **로그아웃:** 화면 오른쪽 위 프로필 카드(이름·사는 곳 옆)의 `로그아웃` 버튼을 누르면 시작 화면으로 돌아갑니다. 화면이 좁으면(900px 이하) 모바일 시작, 넓으면 PC 시작입니다.
- **회원 탈퇴:** `마이페이지 > 내 정보` 맨 아래의 `회원 탈퇴` 버튼 → 확인 창에서 "탈퇴에 동의해요"를 체크해야 `탈퇴하기`가 눌립니다. 탈퇴하면 이 브라우저에 저장된 앱 데이터(일정, 할 일, 가계부, 알림 상태, 커뮤니티 글, AI 대화, 설정)가 모두 삭제되고 시작 화면으로 돌아갑니다.
- 지금은 서버가 없어서 로그인 상태를 따로 저장하지 않습니다. 서버를 붙이면 `components/account.js`에서 로그아웃·탈퇴 API를 호출하도록 바꾸면 됩니다.

#### 홈 화면의 "AI와 대화" 카드
- PC에서만 홈 맨 아래줄, "자취 꿀팁 게시글" 오른쪽에 보입니다(모바일은 하단 AI 탭과 AI 버튼을 씀).
- 분야 칩(분리배출·요리·청소·계약·공과금)을 누르거나, 질문을 입력해서 `물어보기`를 누르거나, `대화 열기`·카드의 빈 곳을 누르면 **AI 메뉴로 이동하지 않고 모달창이 열려서** 그 안에서 대화를 이어갑니다.
- 모달 안에서도 분야 칩과 입력창으로 계속 질문할 수 있고, 대화는 이 브라우저에 저장됩니다. `새 대화`로 비울 수 있습니다.
- 사이드바의 `AI` 메뉴(질문 초안 → 답변 화면)는 그대로 따로 있습니다. 상단의 "AI에게 물어보기" 버튼은 없앴습니다.
- 구성: HTML은 `index.html`(`homeAiCard`, `chatModal`), 모양은 `css/app.css`(`.ai-card`, `.chat-*`), 동작은 `js/components/ai-chat.js`.
- 모바일 하단 메뉴는 홈·**마이페이지**·사진(가운데)·AI·동네 5개입니다. (커뮤니티는 ☰ 전체 메뉴에서 엽니다)

### 4-2. `variants/start-mobile/` (모바일 시작)
| 파일 | 용도 |
|---|---|
| `index.html` | 한 파일로 된 시작 화면. **화면 아래의 `처음이세요? 회원가입` 버튼을 누르면 별도 가입 페이지(`variants/account/signup.html`)로 이동합니다.** 모션은 **화면 아무 곳이나 누르거나 왼쪽 위 `건너뛰기 ›`를 누르면 건너뜁니다**(시작 화면 → 바로 모션, 로봇 등장·줌인 → 문 앞 대기, 문 열림·입장 → 바로 로그인 창). ① 앱 시작 화면(아이콘 + ZIP) → ② 로봇 등장 → ③ 문 옆으로 줌인 → ④ "눌러서 입장" → ⑤ 문이 열리고 로봇이 들어감 → ⑥ 로그인 창. 로그인에 성공하면 `variants/app/` 으로 이동 |

### 4-3. `variants/start-pc/` (PC 시작)
| 파일 | 용도 |
|---|---|
| `index.html` | 한 파일로 된 PC 시작 화면. 마우스 휠로 한 화면씩 넘어가는 7장짜리 소개(첫 화면 → 일정·할 일 → 공과금·월세 → 쓰레기 → AI → 동네 → 시작하기). **로그인 창은 항상 떠 있지 않고**, 위쪽의 `로그인` 버튼이나 `로그인하고 시작` 버튼(첫 화면·마지막 화면)을 누르면 **모달창**으로 열립니다. 위쪽 메뉴와 첫·마지막 화면의 **`회원가입` 버튼**은 같은 창을 가입 모드로 엽니다. 모달이 열려 있는 동안에는 휠·키로 화면이 넘어가지 않고, ×·배경 클릭·Esc로 닫습니다. 로그인에 성공하면 `variants/app/` 으로 이동 |


### 4-4. `variants/account/` (회원가입 · 아이디/비밀번호 찾기)
PC 시작과 모바일 시작이 같이 쓰는 별도 페이지들입니다. 로그인은 각 시작 화면의 모달을 그대로 쓰고, 가입과 찾기만 이 폴더의 페이지로 이동합니다.
- **PC(폭 901px 이상)**: 하늘색 바탕 위에 흰 카드. **모바일(폭 900px 이하)**: 바탕과 위쪽 로고 줄 없이 흰 카드만 화면 가득 보임.
- 페이지의 "로그인"·로고 링크는 화면 폭에 따라 PC 시작 또는 **모바일 시작(`#login`)**으로 돌아감. 모바일 시작은 `#login`으로 열리면 시작 화면(아이콘)을 건너뛰고 로봇이 나타나 문이 저절로 열리고 로봇이 들어간 뒤 로그인 모달이 뜸.

| 파일 | 용도 |
|---|---|
| `signup.html` | **회원가입 전용 페이지**. PC 시작의 "회원가입" 버튼과 로그인 창 아래 "회원가입" 링크가 이동. "로그인 정보 · 회원 정보 · 가입 약관 동의" 3구역 형식이고, 약관은 서비스 이용약관(필수) · 개인정보 처리방침(안내 확인, 필수) · 커뮤니티·AI 운영 정책(필수) |
| `signup.js` | 회원가입 페이지의 동작: 입력 검사, 휴대전화 인증(시안: 아무 6자리), 약관 전체 동의·상세보기, 가입하면 앱으로 이동 |
| `find.html` | **아이디 찾기 · 비밀번호 찾기 페이지**. 위쪽 탭으로 둘을 오갈 수 있고, 로그인 창의 "아이디 찾기"는 `find.html#id`, "비밀번호 찾기"는 `find.html#pw`로 각각 이동. 둘 다 **휴대전화 인증**으로 본인을 확인함 |
| `find.js` | 찾기 페이지의 동작: 탭 전환, 휴대전화 인증(시안: 아무 6자리). **아이디 찾기** = 닉네임 + 휴대전화 → 아이디를 가리지 않고 그대로 보여 줌. **비밀번호 찾기** = 아이디 + 휴대전화 → 메일 발송 없이 같은 화면에서 바로 새 비밀번호를 두 번 입력해 재설정 |
| `account.css` | 회원가입·찾기 두 페이지가 같이 쓰는 모양 (라벨은 왼쪽, 입력칸은 밑줄만 있는 폼) |
| `account.js` | 두 페이지 공통: "로그인"·로고 링크가 갈 시작 화면(PC/모바일)을 화면 폭으로 정함 |
| `terms.js` | 회원가입 약관 내용(예시 문구): 서비스 이용약관, 개인정보 처리방침, 커뮤니티·AI 운영 정책. 가입 페이지의 "상세보기"가 읽어 감. 실제 서비스 전에 법률 검토 필요 |
