# 전세 대출 이자 자동 기록

## 동작

- 첫 로그인 설문에서 전세·대출 있음을 선택하거나 가계부 → 지출 → 고정 지출의 전세 대출 이자 카드에서 설정한다.
- 대출금은 원, 연 이율은 퍼센트(0~100, 소수 둘째 자리), 매월 납부일은 1~31일, 자동 기록 시작일은 날짜로 입력한다.
- 원금을 유지하는 이자 납부 모델이다. 월 예상 이자는 `Math.round(원금 × 연 이율 / 100 / 12)`이다. 원금 상환, 일할 계산, 변동 금리 자동 조회, 휴일 이연, 실제 계좌 출금은 제공하지 않는다. 은행 실제 청구액과 차이가 있을 수 있음을 폼에 표시한다.
- 한국 시간의 납부일이 되면 별도의 이자 지출 내역에 기록한다. 29~31일이 없는 달은 말일을 적용한다. 기록 시작일 이전의 납부일은 생성하지 않는다.
- 실행 시·1분 간격·포커스 복귀 시 동기화한다. 앱을 실행하지 않은 기간의 지난 납부일은 다음 실행 때 보완한다. 브라우저를 닫은 동안 서버 작업이 실행되는 구조가 아니다.
- 회원과 대출을 구분하고 `대출 ID:YYYY-MM`을 중복 방지 키로 쓴다. 새로고침·중복 동기화로 같은 월을 두 번 기록하지 않는다.
- 금액·금리·납부일 수정 전에 지난 납부일을 이전 조건으로 확정한다. 기존 내역의 원금·금리·금액 스냅샷은 보존하고 아직 기록하지 않은 월부터 변경을 적용한다. 수정 시 시작일은 유지한다.
- 자동 기록 중지는 기존 기록을 보존하고 이후 기록을 막는다. 다시 설정하면 기존 대출 ID를 재사용해 같은 달 중복을 방지하고 새 시작일부터 재개한다. 현재 로그인한 회원의 데이터 초기화는 해당 회원의 대출 설정과 이자 내역만 삭제한다.

## 합계

고정 지출 요약과 납부 체크리스트에는 이번 달 예정 이자와 기록액을 구분한다. 홈 지출 구성·내 정보 총지출·AI 지출 요약에는 납부일에 기록된 이자만 한 번 포함한다. 공과금 항목이나 기타 지출에 복사하지 않아 이중 집계를 막는다.

## 저장과 운영

현재 설정·내역은 Zustand persist의 `zip-loan-interest`에 저장된다. 기존 설문 데이터에는 금리·납부일이 없으므로 금리를 임의로 채우거나 자동으로 활성화하지 않는다. 고정 지출 화면에서 직접 설정할 수 있다.

서버 연결 시 소유자 권한 검사, 대출·월별 UNIQUE 키, 납부 스냅샷을 DB에 저장하고 서버 작업으로 동기화해야 한다. 이 변경은 은행 자동이체 기능이 아니다.

## 검증

`node --test tests/loan-interest.test.mjs`

납부일 경계, 월말·윤년, 한국 날짜, 미실행 기간, 재접속 중복, 조건 변경, 중지, 회원 구분, 지출 이중 집계를 검증한다.
