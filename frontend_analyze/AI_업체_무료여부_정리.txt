1. 한 줄 결론
====================================================================
- 개발과 시연은 무료로 가능하다. (Gemini 무료 티어가 가장 현실적)
- 실제 서비스로 운영하려면 결국 유료다. 다만 작은 모델은 한 번 호출이 매우 저렴하다.
- 사진/파일 입력은 대부분의 주요 AI 가 기본으로 지원해서, 이것 때문에 비용이 갈리지는 않는다.
  (비용은 "기능"이 아니라 "사용량"으로 정해진다. 사진은 글보다 토큰을 더 쓴다.)


2. 업체별 무료 여부 (2026-11-01 확인 기준)
====================================================================
업체               API 무료 여부                   메모
-----------------  ------------------------------  -----------------------------------------------
Gemini (구글)      무료 티어 있음                  요청 수/토큰 수 제한이 낮음. 무료 쪽은 입력 데이터가
                                                   제품 개선에 쓰일 수 있다는 조건이 붙음.
                                                   무료 티어에서도 이미지 입력이 무료로 표시됨(모델에 따라 다름).
Grok (xAI)         지속적인 무료 티어는 없는 것으로 보임  출처마다 말이 다름. 가입 시 소액 크레딧이 있다는 곳도
                                                   있으나 공식 확인이 안 됨 (만료 기간이 있다는 설명도 있음).
                                                   현재 이미지 입력(vision) 단가는 확인하지 못함.
Claude (Anthropic) 지속적인 무료 API 는 없음       가입 시 소액 테스트 크레딧이 있다는 설명은 제3자 출처뿐.
                                                   앱(웹) 채팅의 무료 플랜과 API 요금은 별개.
                                                   이미지는 추가 토큰으로 계산되어 청구됨.

세부
  [Gemini]
    - 제한은 프로젝트 단위로 "분당 요청 수 / 분당 입력 토큰 수 / 하루 요청 수"로 걸리고,
      하나라도 넘으면 오류가 난다.
    - 유료 입력 단가 예: 일부 모델에서 텍스트/이미지/영상 입력이 100만 토큰당 $0.10~$0.15 수준으로
      표시됨 (어느 모델의 값인지는 공식 페이지에서 확인 필요).
    - 일부 포럼 글에서 "결제 정보가 없는 무료 계정은 쿼터가 있어 보여도 거절되는 경우"가 보고됨.
    - 이미지 "생성" 모델은 유료 단가가 따로 있고 무료 티어에 안 되는 모델도 있음
      (우리는 이미지 "읽기"만 필요하므로 생성은 해당 없음).
  [Grok]
    - 출시 초기(2024)에는 베타 기간 무료 크레딧이 있었으나 종료된 것으로 보인다는 자료가 많음.
    - 현재 텍스트 모델 단가는 자료마다 달라서 정확한 값을 적지 않는다. 공식 페이지 확인 필요.
  [Claude]
    - 소형 모델(Haiku 계열)은 단가가 낮은 편이라는 자료가 있다.
      어느 모델이 현재 최신인지, 단가가 얼마인지는 출처마다 달라 공식 페이지 확인 필요.
    - 긴 입력(예: 10만 토큰 초과)은 단가가 오르는 구간이 있다는 자료가 있음.


3. 비용 감각 (추정, 정확하지 않음)
====================================================================
- 소형 모델의 입력 단가가 100만 토큰당 $0.10 안팎이라는 자료가 여러 곳에 있다.
- 이 숫자로 단순 계산하면 입력 1,000 토큰은 약 $0.0001(대략 0.1원대)이다.
  출력 단가는 보통 입력보다 비싸다 (자료상 3~5배 수준).
- 그래서 질문 1번이 대략 1원 안팎에서 몇 원 수준일 것으로 "추정"된다.
  모델, 답변 길이, 사진 개수에 따라 크게 달라지므로 실제로는 직접 측정해야 한다.
- 측정 방법: 테스트 호출 후 업체 콘솔의 사용량/청구 화면에서 토큰 수와 금액을 확인한다.


4. 앱의 AI 10개 기능이 요구하는 수준
====================================================================
10개 모두 최신 주요 모델이면 충분한 난이도다. 다만 AI 가 하는 일이 다르다.

기능(분야 코드)            AI 에 필요한 것            메모
-------------------------  -------------------------  ------------------------------------------------
qna 자유 질문              글 이해와 답변             쉬움
contract 계약·보증금       글 이해와 답변             틀린 법률 정보가 위험. "법률 조언이 아님" 안내 필요
bill 공과금·생활비         글 이해와 답변             쉬움
trash 분리배출             사진 이해                  사진 입력 지원 모델 필요
cook 냉장고 요리           사진 이해                  재료 인식 정확도가 중요
clean 청소·곰팡이          사진 이해                  얼룩/곰팡이 구분
landlord 집주인 문자       글쓰기 + 사진(선택)        문장 품질(정중한 어투)이 중요. 누수 사진 등을 받을 수 있음
nearby 근처 탐색           질문 해석만                장소 정보는 AI 가 아니라 우리 DB(places)나 카카오 로컬에서 가져와야 함.
                                                      AI 에게 맡기면 없는 가게를 지어낼 수 있음
summary 이번 달 지출 요약  숫자를 문장으로            숫자는 서버가 계산해서 AI 에 넘기고, AI 는 문장만 만든다
guide 사용 방법            앱 안내                    앱 기능 위치를 AI 에 미리 알려주면 됨. AI 없이 정해진 안내로도 가능

사진을 받는 분야: trash, cook, clean, landlord (프론트 topics.ts 의 photo 값 기준)
-> 10개 중 3개(nearby, summary, guide)는 AI 의 "똑똑함"보다 우리 데이터 연결이 더 중요하다.

파일(PDF 등) 입력
  - 계약서 PDF 를 올려 "특약을 요약해줘"처럼 쓰고 싶다면 파일 입력 지원이 필요하다.
  - 주요 모델이 대부분 지원하지만, 이번에 업체별로 확인하지 못했다. 선택 전에 공식 문서 확인.
  - 현재 앱 화면은 사진 첨부(카메라/사진)만 있다. 파일 입력은 화면 추가가 필요하다.


5. 추천
====================================================================
1) 개발/시연은 Gemini 무료 티어로 시작한다.
   - 키만 받으면 사진 입력도 시험해 볼 수 있다.
2) AI 호출 인터페이스(AiClient)를 만들어 둔다. (백엔드_기술스택_추천.txt 7-1 참고)
   - 나중에 사용자가 늘면 코드는 그대로 두고 설정만 유료 업체로 바꾼다.
3) 무료 티어를 쓸 때는 개인정보를 AI 에 보내지 않는다.
   - 이름, 전화번호, 정확한 주소는 서버에서 걸러낸다.
   - 무료 쪽은 입력 데이터가 제품 개선에 쓰일 수 있다는 조건이 있다.
4) 실제 서비스로 갈 때는 하루 사용량 제한(ai_usage_daily)을 두고 작은 유료 모델로 시작한다.
5) 같은 질문 10개(분야별 1개)로 후보 2~3곳을 직접 비교해서 기본 업체를 정한다.
   (질문 예시와 점수표는 백엔드_기술스택_추천.txt 7-1 의 C 참고)


6. 비용 줄이는 방법
====================================================================
- 하루 사용량 제한 (DB 에 ai_usage_daily 표가 이미 있음)
- 사진은 서버에서 크기를 줄여서 보낸다 (토큰 절약)
- 답변 길이를 제한한다
- 간단한 질문은 작고 저렴한 모델, 어려운 질문만 큰 모델
- 같은 질문의 답은 캐시한다 (분리배출처럼 반복되는 질문에 효과적)
- 지출 요약처럼 계산이 가능한 부분은 AI 가 아니라 서버가 계산한다
- 오픈소스 모델을 직접 서버에 띄우는 방법도 있으나 서버 비용과 품질 문제로 이 프로젝트엔 과하다


7. 개인정보 / 약관
====================================================================
- AI 에 보내는 질문과 지출 요약에는 사용자 정보(월세, 지출 등)가 섞일 수 있다.
- 개인정보 처리방침에 "AI 제공 업체에 질문 내용이 전달된다"는 내용을 넣는다.
  해외 업체면 국외 이전 고지도 필요하다. 지금 약관은 초안이라 법률 검토 때 함께 본다.
- 업체의 데이터 사용 조건(학습에 쓰는지, 보관 기간)은 무료/유료에 따라 다를 수 있으니
  가입 시점에 약관을 읽는다.
