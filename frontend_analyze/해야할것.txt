ZIP 해야 할 것 (백엔드 만들기 전체 순서)
====================================================================
작성일: 2026-11-01
전제: 화면(프론트, React)은 이미 다 만들어져 있고, 지금 만들어야 하는 것은 Spring 백엔드다.
상세 체크리스트: 백엔드_필수기능_목록.txt
기술 선택: 백엔드_기술스택_추천.txt / 화면별 상세: 백엔드_연동_가이드.txt

규모 감각
--------------------------------------------------------------------
화면이 이미 있어서 API 가 약 80개다.
1단계만 만들어도 로그인 화면이 바로 실제 서버와 연결된다.
그다음은 3단계(일정, 월세, 가계부)가 홈 화면의 핵심이라 효과가 가장 크다.


0단계. 바탕 작업
====================================================================
[ ] Spring 프로젝트 생성 (Java 21, Gradle), 포트 8080, 주소는 모두 /api 로 시작
[ ] MySQL 연결, db/schema.sql 적용 (Docker Compose 추천)
[ ] JWT 로그인 검사 (Authorization: Bearer <accessToken>)
[ ] 오류 응답 형식 통일: { "message": "..." }
[ ] 401(토큰 없음/만료), 403(권한 없음), 404(남의 데이터) 규칙
[ ] CORS 설정, 시간대 Asia/Seoul
[ ] "내 데이터만 접근" 규칙
[ ] DB id(BIGINT)를 JSON 에서 문자열로 내려주기
[ ] 서버 비밀 키는 .env 에만 (깃에 올리지 않기)


1단계. 회원가입 / 로그인 (프론트에 호출 코드가 이미 있음)
====================================================================
[ ] 회원가입: 입력 검사(아이디, 비밀번호, 닉네임), 중복 방지, 비밀번호 해시, 약관 동의 기록
[ ] 로그인: 아이디 또는 이메일, 로그인 유지, 정지 계정 차단, 마지막 로그인 시각 기록
[ ] 내 정보 조회/수정: 닉네임, 소셜 첫 가입 시 주소와 약관 동의
[ ] 로그아웃
[ ] 비밀번호 변경
[ ] 회원 탈퇴: 개인 데이터 정리, 정지 기록은 유지
[ ] 첫 로그인 판단: 서버가 firstLogin 값을 내려줘서 설문 화면으로 보내기
[ ] 프로필: 한 줄 소개, 사진, 캐릭터


2단계. 인증 보조 기능
====================================================================
[ ] 휴대폰 인증번호 발송 / 확인 (개발 중에는 고정 인증번호로 우회 가능)
[ ] 아이디 찾기
[ ] 비밀번호 재설정
[ ] 소셜 로그인 (카카오, 네이버, 구글)


3단계. 생활 관리 (홈과 마이페이지의 핵심)
====================================================================
[ ] 설정과 동네: 월세 납부일, 월세, 입주월, 계약 끝나는 달, 동네 목록, 위치로 동네 인증
[ ] 첫 로그인 설문 저장: 생년월일, 주소, 월세/전세, 보증금, 관리비, 대출, 수입
      (저장할 칸과 API 를 먼저 설계해야 함)
[ ] 일정: 추가, 수정, 삭제, 완료 체크, 기념일, 매년 반복, 검색
[ ] 일정 카테고리: 추가, 이름 변경, 삭제, 항목 버튼
[ ] 쓰레기 배출: 동네별 요일 정보
[ ] 월세: 달마다 납부 체크
[ ] 고정지출: 추가, 납부 체크, 해지, 태그(공과금, 통신, 구독, 관리비, 기타)
[ ] 가계부: 수입/기타 지출 기록과 삭제, 분류 목록, 통계
[ ] 대출 이자 자동 기록 (API 약속이 아직 없어서 설계가 필요함)


4단계. 알림 / 메모 / 고객센터
====================================================================
[ ] 알림: 목록, 읽음 처리, 삭제
      서버가 만드는 알림: 월세 D-day, 일정/기념일 D-3, 쓰레기 배출
[ ] 메모: 목록, 추가, 자동 저장 수정, 삭제, 고정, 체크리스트
[ ] 고객센터: 문의 작성/조회, 관리자 답변


5단계. 커뮤니티
====================================================================
[ ] 글 목록 (동네 범위, 카테고리, 검색), 상세, 작성, 수정, 삭제
[ ] 댓글: 작성, 수정, 삭제
[ ] 좋아요
[ ] 파일 첨부 (업로드)
[ ] 신고
[ ] 내 글/내 댓글 여부를 서버가 계산해서 내려주기


6단계. 관리자 / 이용 정지
====================================================================
[ ] 관리자 권한 검사, 통계, 회원 목록과 검색
[ ] 정지 (1, 3, 5, 10일, 영구)와 경고, 정지 해제, 일괄 처리, 조치 이력
[ ] 정지된 아이디/닉네임/휴대폰으로 재가입 차단
[ ] 경고 확인("확인했어요") 기록
[ ] 글/댓글 삭제, 신고 처리
[ ] 약관 조회


7단계. AI / 지도
====================================================================
[ ] AI 상담 10개 분야
      자유 질문, 사용 방법, 근처 탐색, 분리배출, 냉장고 요리,
      청소·곰팡이, 계약·보증금, 집주인 문자, 공과금·생활비, 이번 달 지출 요약
      대화 저장, 사진 입력, 하루 사용량 제한
[ ] 지도: 장소 종류와 목록, 즐겨찾기, 지도 설정, AI 장소 검색
[ ] 날씨와 주소 검색을 서버가 대신 호출하고 캐시


결정이 필요한 것

[ ] 커뮤니티 카테고리의 한글과 영문 코드 매핑
[ ] Flyway 사용 여부 (DB 담당 문원과 상의)
